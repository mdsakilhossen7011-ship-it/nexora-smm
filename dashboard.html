Developer API

Connect your NEXORA account to another website or SMM panel.
API v2

Generate a private API key, then use the API from your website's server. Your API orders use your NEXORA wallet balance and appear in your normal order history.

Your API Key

Checking API key…

Not generated

Keep this key secret. Never put it in public HTML, browser JavaScript, or share it with anyone. If exposed, revoke it and generate a new one.

Connection details

Method: POST · Content-Type: application/x-www-form-urlencoded or application/json

Supported actions

  • services — list enabled services, IDs, rates and limits.
  • balance — check your wallet balance in BDT.
  • add — place an order using service, link and quantity.
  • status — check an order using its order ID.

Example: list services

curl -X POST "/api/v2" \
  -d "key=YOUR_API_KEY" \
  -d "action=services"

Example: place an order

curl -X POST "/api/v2" \
  -d "key=YOUR_API_KEY" \
  -d "action=add" \
  -d "service=SERVICE_ID" \
  -d "link=POST_URL_OR_PLAYER_UID" \
  -d "quantity=100"

The service ID is the UUID returned by the services action. Rates are BDT per 1,000 units. Free Fire services use the player's UID in the link field and the package quantity shown in the service limits. Orders are subject to service availability, account balance and NEXORA order fulfilment settings.
